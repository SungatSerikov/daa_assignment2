# Assignment 2: Algorithmic Analysis, Correctness and Performance Trade-offs

This project implements and studies a dynamic array, a linked list, and a min-heap in Java.

## Current progress

- Dynamic array and singly linked list implementations and correctness tests are complete.
- Min-heap, complexity analysis, benchmarks, and results will be added in later steps.

## Compile and run the current tests

From the project directory, run:

```text
javac -d out src/DynamicArray.java src/LinkedList.java src/Tests.java
java -cp out Tests
```

The implementations use integers because the assignment's workloads use random integers.
